# TESS logo assets
- tess-original.jpg is the unchanged logo provided by the owner.
- tess-logo.svg embeds the original JPEG, frames the existing logo bounds, and uses an SVG display filter to show the white artwork on a transparent background. The original image file is not altered.
- tess-mark.svg is a vector rendering of the two angular pieces in the owner's symbol.
The shared Logo component uses these SVGs as alpha masks, with the theme foreground color.
The full wordmark appears in the global header/footer and the preview toolbar; the mark appears in the preview sidebar and homepage composition. The browser icon uses the same symbol.
Generated background-removal variants were rejected because their edges did not preserve the supplied artwork cleanly. They are not used by the website.
